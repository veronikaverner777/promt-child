Панель готова к работе с Supabase Auth, базой PostgreSQL и Storage. Подключение выполняется один раз. Репозиторий остаётся promt-child.

Используйте только публичный Publishable или anon ключ. Никогда не помещайте service_role, sb_secret_…, пароль базы или JWT secret в сайт.

1. Создайте проект

Откройте Supabase Dashboard, создайте проект. В настройках найдите Project URL и API Keys → Publishable key.

2. Выполните SQL

Откройте SQL Editor → New query. Скопируйте весь SQL-файл схемы из репозитория и нажмите Run. Он создаст таблицы, RLS и приватное хранилище обложек.

3. Назначьте администратора

  1. Authentication → Users → Add user → Create new user: создайте email/пароль, подтвердите email через Auto Confirm User.
  2. Скопируйте User UID.
  3. В SQL Editor выполните, заменив пример на UID:
insert into private.admin_users (user_id)
values ('ВАШ-USER-UID'::uuid)
on conflict (user_id) do nothing;

Роль назначается только через SQL. Публичной регистрации на сайте нет. При необходимости отключите Allow new users to sign up.

4. Укажите адрес Auth

В Authentication → URL Configuration → Site URL задайте https://veronikaverner777.github.io/promt-child/. Используется вход по email и паролю; OAuth и magic links не требуются.

5. Добавьте публичные переменные GitHub

Откройте репозиторий → Settings → Secrets and variables → Actions → Variables и добавьте:

  • VITE_SUPABASE_URL — Project URL.
  • VITE_SUPABASE_PUBLISHABLE_KEY — публичный sb_publishable_… или старый anon ключ.

После объединения изменений в main запустите Actions → Publish AI PLAYGROUND to GitHub Pages → Run workflow → main. Переменные встраиваются при сборке, поэтому после их изменения нужна новая публикация.

6. Проверьте публикацию

Вернитесь в админ-панель, войдите и создайте категорию. Добавьте промпт, проверьте предпросмотр и сохраните черновик. Нажмите Опубликовать и откройте общий каталог в приватном окне. Черновики посетителям недоступны.

Другие вкладки обновляются каждые 30 секунд и при возврате фокуса. Изменения в каталоге больше не требуют пересборки сайта. Обложки: JPG/PNG/WebP, до 5 МБ. Данные хранятся в Supabase, а не в браузере администратора.

# AI PLAYGROUND

Интерактивная образовательная платформа на русском языке для детей 7–17 лет. Четыре самостоятельных проекта, каталог с фильтрами и избранным, конструктор промптов. Для посетителей не требуются регистрация и платежи. Игры и конструктор работают без ключей API и сервера данных; новый каталог DeepSeek опционально подключается к Supabase.

## Быстрый запуск

Требуется Node.js 22+ и npm.

```bash
npm ci --cache /tmp/ai-playground-npm
npm run dev -- --port 5173
```

Для production:

```bash
npm run build
npm run preview
```

Готовый `dist/` можно разместить на любом хостинге статических сайтов. Навигация по hash-маршрутам не требует специальных правил переадресации.

## Что работает

- **Case Battle** — два бесплатных виртуальных кейса, анимированная рулетка, открытые вероятности, коллекция, обмен находок на игровые очки и бесплатное пополнение баланса. Игровые очки не имеют денежной стоимости. Награда сохраняется сразу, поэтому смена страницы во время анимации не теряет находку.
- **3D Car Studio** — процедурная 3D-модель на Three.js, вращение мышью и касанием, масштабирование, шесть цветов и собственный оттенок, три варианта дисков, подсветка, автовращение, сброс ракурса и скачивание PNG. Требуется WebGL. Ограничены pixel ratio и частота кадров; неподвижная сцена не перерисовывается. Геометрия и материалы освобождаются при выходе.
- **Mini Market** — восемь товаров, подробные карточки, поиск, категории, сортировка, корзина, количества, удаление, тестовое оформление и история заказов. Никаких персональных данных, оплаты и доставки.
- **Dream Room** — план комнаты, восемь видов мебели, перетаскивание, поворот, дублирование и удаление, цвет стен, три покрытия пола, сетка, именованные сохранения (до 12). Стрелки перемещают выбранную мебель, Shift ускоряет, R поворачивает, Delete удаляет. До 30 предметов в комнате.
- **Создай свою версию** — выбор основы, стиля, уровня и дополнительной идеи; локальная генерация редактируемого промпта и копирование. Сервис не обращается к языковой модели: готовый текст можно использовать в ИИ-помощнике.

Игровой прогресс, настройки и избранное сохраняются в `localStorage` с префиксом `aip.` на текущем устройстве. Очистка данных сайта сбрасывает их. При недоступном хранилище игры продолжают работать в текущем сеансе. Каталог DeepSeek хранится в Supabase; для управления используется отдельный сеанс Supabase Auth.

## Архитектура

```text
src/
  App.tsx                     # Оболочка, каталог, hash-навигация, реестр lazy-модулей
  data.ts                     # Типизированные метаданные проектов и фильтров
  hooks.ts                    # Хук локального сохранения
  components/
    Artwork.tsx               # Собственные SVG-обложки и иллюстрация главной
    DialogAccessibility.tsx   # Фокус диалогов, Escape, возврат фокуса
    PromptBuilder.tsx         # Конструктор промптов
  projects/
    CaseBattle.tsx
    CarStudio.tsx
    MiniMarket.tsx
    DreamRoom.tsx
  styles.css                  # Адаптивная тема и стили проектов (Tailwind CSS 4)
tests/platform.spec.ts        # Сквозные браузерные проверки
```

Для добавления проекта расширьте `ProjectId` и список `projects` в `data.ts`, добавьте самостоятельный React-модуль, его lazy-импорт и запись в `registry` в `App.tsx`, обложку и шаблон промпта. Каталог и общая навигация используют метаданные и не требуют переписывания. Three.js загружается только при открытии Car Studio. Шрифты Manrope и встроенные иллюстрации обслуживаются локально. Обложки каталога DeepSeek загружаются из Supabase Storage после подключения.

## Проверки

```bash
npm run build
npm run test:e2e
```

Playwright запускает Vite автоматически. По умолчанию используется установленный `/usr/bin/chromium`. Для другого браузера задайте `PLAYWRIGHT_CHROMIUM_PATH=/полный/путь/к/chromium`. В headless-тестах WebGL использует SwiftShader.

Семь сквозных сценариев проверяют каталог, фильтры и избранное; кейсы и баланс; корзину и историю заказов; перемещение и сохранение комнаты; настоящую отрисовку WebGL, изменение настроек и экспорт изображения; генератор промптов; мобильную навигацию и отсутствие горизонтального переполнения. Сохранение проверяется после перезагрузки страницы.

Форматирование: `npx prettier --write src tests *.ts *.json index.html README.md`.

## Каталог DeepSeek и админ-панель

- `/promt-child/#prompts` — опубликованные промпты, поиск, категории, полный текст и копирование.
- `/promt-child/#admin` — вход администратора, создание и редактирование, обложки и теги, предпросмотр, публикация, удаление, категории и порядок карточек.
- `src/catalog/` — типы, API и обновляемый публичный каталог; `src/admin/` — защищённый интерфейс; `src/lib/supabase.ts` — клиент только с публичным ключом.
- `supabase/migrations/202611010001_deepseek_catalog.sql` — база, роли, RLS, приватные изображения и атомарная перестановка.

Подключение: [SUPABASE_SETUP.md](SUPABASE_SETUP.md). До подключения нет открытого редактора и тестового обхода входа. Существующие игры и конструктор сохраняются.

Проверки новой интеграции: `npm run test:security` (20 проверок PostgreSQL/RLS) и `npm run test:admin` (браузерный интерфейс с изолированными ответами Supabase; реальные учётные данные не используются). Для подключения и полноценной проверки на вашем облачном Supabase выполните пошаговую инструкцию.
